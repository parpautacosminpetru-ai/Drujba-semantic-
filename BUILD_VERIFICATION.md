# Verificarea buildului Android

Acest fișier declanșează verificarea completă a aplicației în GitHub Actions:

- formatare și analiză statică Flutter;
- teste automate;
- compilarea APK-ului release;
- verificarea manifestului offline;
- publicarea APK-ului ca artifact.

Pentru v2, aceeași verificare validează suplimentar reactorul semantic
axiomatic direcțional, dovada fiecărei fuziuni, proveniența formelor, zăvorul
pe monolit și replay-ul OCR pozițional înainte de construirea APK-ului.
